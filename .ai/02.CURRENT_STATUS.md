# Project Status

## Overall Status

The Enrollment Domain Discovery is closed, the AUDIT-001 documentation reconstruction has completed formal technical review, and the temporary User lockout policy required by E004.1 has been approved through ADR-0016.

PR #3 remains draft and pending new formal review. No migration was executed on the configured `UEAnt` database.

## Last Completed Work

E004.1 — Identity & Access Baseline:

- User is implemented as an independent Aggregate Root linked to Person;
- the active login and logout flow uses the IdentityAccess vertical slice;
- ADR-0016 is enforced through a typed, configurable policy;
- authentication now loads and locks User inside the transaction and performs one password verification per attempt;
- migration 014 is forward-only, preflights incompatible identifiers and preserves active-model state on repeated execution;
- the administrator seeder requires an external initial credential and preserves existing User password and status;
- local domain, application, persistence, HTTP and real-session validations pass.

## Current Risks

- The revised MariaDB 10.4 scenarios for UTC, row locking, repeated migration, duplicate preflight and seeder preservation were not executed because no authorized isolated server was available.
- Official catalog values not yet supplied remain a data-master concern, not a schema decision.
