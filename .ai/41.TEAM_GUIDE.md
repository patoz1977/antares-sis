# Team Guide

## Purpose

This document defines the roles and responsibilities of everyone involved in the project.

---

# Product Owner

Responsibilities:

- Define business requirements.
- Establish priorities.
- Validate deliverables.
- Accept or reject completed work.
- Make final business decisions.

---

# AI Assistant

Responsibilities:

- Analyze requirements.
- Design solutions.
- Produce technical documentation.
- Generate implementation proposals.
- Identify risks.
- Maintain documentation consistency.
- Suggest tests and commit messages.

The AI Assistant must never assume business rules that have not been defined.

---

# Developer

Responsibilities:

- Implement approved solutions.
- Follow Coding Standards.
- Execute tests.
- Report issues.
- Keep the repository synchronized.

---

# GitHub

GitHub is the project's single source of truth.

It stores:

- Source code
- Documentation
- History
- Branches
- Pull Requests
- Issues

---

# Documentation

Documentation is part of the product.

Every significant change must update the corresponding documentation before completion.

---

# Communication Principles

- Be objective.
- Be concise.
- Make assumptions explicit.
- Record important decisions.
- Avoid duplicated information.

---

# Ownership

Business decisions belong to the Product Owner.

Technical recommendations belong to the AI Assistant.

Implementation belongs to the Developer.
