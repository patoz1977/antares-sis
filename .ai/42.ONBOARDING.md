# Onboarding Guide

## Purpose

This document helps new contributors become productive as quickly as possible.

---

# Before You Start

Ensure you have:

- Repository access.
- Development environment configured.
- Latest version of the repository.
- Ability to run the application locally.

---

# Before Making Changes

Always:

- Pull the latest changes.
- Review the affected modules.
- Understand the business objective.
- Review related documentation.
- Identify impacted components.

---

# During Development

- Follow the official workflow.
- Keep changes focused.
- Update documentation when required.
- Record significant decisions.

---

# Before Finishing

Verify:

- Requirements are implemented.
- Tests pass.
- Documentation is updated.
- Commit is ready.
