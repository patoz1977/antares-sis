# Documentation Principles

- GitHub is the single source of truth.
- Every document has a single responsibility.
- Avoid duplicated information.
- Documentation evolves together with the software.
- Business decisions precede implementation.
- Every significant architectural decision must be recorded in `20.DECISIONS.md`.
- Documents should reference each other instead of duplicating content.
